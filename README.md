# zyadelzyat.github.io

Personal security research portfolio built with GitHub Pages and the Hacker theme.

## Add a new post

1. Open the `_posts` folder in this repository.
2. Create a file named `YYYY-MM-DD-short-title.md`.
3. Start it with:

```yaml
---
layout: default
title: Your article title
description: One-sentence description
category: Detection engineering
---
```

Write the article in Markdown under the closing `---`, then commit the file. GitHub Pages rebuilds the site automatically.
